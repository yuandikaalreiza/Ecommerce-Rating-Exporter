# Ecommerce Rating Exporter / Ekspor Rating Ecommerce

Repository ini berisi dua ekstensi Chrome yang dimuat secara terpisah. Masing-masing hanya aktif pada Seller Center platformnya sendiri.

This repository contains two separately loadable Chrome extensions. Each runs only on its own platform's Seller Center.

| Platform | Folder to load in Chrome / Folder yang dimuat di Chrome | Documentation |
|---|---|---|
| Shopee | [`shopee-rating-exporter`](shopee-rating-exporter/) | [Shopee README](shopee-rating-exporter/README.md) |
| TikTok Shop | [`tiktok-rating-exporter`](tiktok-rating-exporter/) | [TikTok README](tiktok-rating-exporter/README.md) |

## Instalasi / Installation

1. Buka / Open `chrome://extensions`.
2. Aktifkan / Enable **Developer mode**.
3. Klik / Click **Load unpacked**.
4. Pilih salah satu folder ekstensi di atas. Ulangi langkah ini untuk memuat kedua ekstensi.

Jangan pilih folder repository utama ini sebagai extension. Pilih `shopee-rating-exporter` untuk Shopee atau `tiktok-rating-exporter` untuk TikTok Shop.

Do not select this repository root as an extension. Select `shopee-rating-exporter` for Shopee or `tiktok-rating-exporter` for TikTok Shop.
